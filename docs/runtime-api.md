# Runtime API — `runtime/canvas-video.js`

A single, zero-dependency script that exposes `window.CV`. A composition is one HTML file:

```html
<!doctype html><html><head><meta charset="utf-8">
<link href="https://fonts.googleapis.com/css2?family=Geist:wght@400;800&display=block" rel="stylesheet">
</head><body>
<script src="build/narration.js"></script>     <!-- optional: generated by TTS -->
<script src="canvas-video.js"></script>        <!-- the runtime -->
<script>
const { ease, fx, draw } = CV;
CV.create({
  width: 1920, height: 1080, fps: 30, background: '#0b0b0f', lang: 'en-US',
  scenes: [
    { id: 'hook', draw(ctx, s) { /* pure function of s.t */ } },
    { id: 'next', transition: { type: 'push', direction: 'left', duration: 0.6 }, draw(ctx, s) { … } },
  ],
});
</script></body></html>
```

Open the file in a browser to get a **preview player**: Space plays or pauses, ←/→ steps one frame, Shift+←/→ steps one second, click the bar to scrub, and `#12.5` in the URL jumps to 12.5 s. Narration audio plays in sync if it has been generated. The renderer loads the same file with `?render=1`.

## The determinism contract

- `draw(ctx, s)` must be a **pure function of time**: same `s.t`, same pixels.
- Don't use `Date.now()`, `performance.now()`, `Math.random()`, `setTimeout`, CSS animations or DOM elements for visuals.
- Don't mutate state across frames. Precompute data at load time (seeded with `CV.rand(seed)`). Caches that are pure are fine, for example a pre-rendered texture.
- The renderer may render frames out of order and in parallel pages. Any hidden state will flicker.

## `CV.create(config)`

| Key | Default | Meaning |
|---|---|---|
| `width`, `height` | 1920×1080 | Design size in px (the coordinates you draw in). Must be even. |
| `fps` | 30 | Frame rate (24/25/30/60). |
| `background` | `#000` | Fill painted before each scene (scene `background` overrides it). |
| `lang` | from narration, else `en` | Drives caption rules (CJK vs Latin). |
| `fonts` | `[]` | Extra font specs to preload. Fonts actually drawn are detected automatically. |
| `scenes` | — | Array of scenes (below). |
| `transition` | cut | Default transition *into* every scene after the first. |
| `voiceDelay` | `overlap/2 + 0.25` | Seconds from scene start to the first spoken word. |
| `tail` | `0.55` | Seconds held after the voice ends. |
| `subtitles` | — | `{ burn, maxChars, minChars, punctuation: 'strip'\|'keep', style: {...} }` |
| `overlay(ctx, g)` | — | Drawn on top of every frame (chrome, grain, progress bar). `g = {T, frame, W, H, u, duration, p, scenes}` |
| `music` | — | Path to a music bed (relative to the project), mixed and ducked by the renderer. |
| `setup()` | — | Async hook awaited before rendering (load data, pre-render textures). |
| `pixelRatio` | 1 | Supersampling factor (`--scale` on the CLI overrides it). |

### Scenes

```js
{
  id: 'specs',                 // also the narration segment id
  duration: 4,                 // fixed length (s) — or omit and let the voice decide
  minDuration: 3, maxDuration: 8,
  narration: 'specs' | false,  // which narration segment (defaults to id)
  say: 'text',                 // inline narration text (estimated timing until TTS runs)
  voiceDelay: 0.3, tail: 1.2,  // per-scene overrides
  background: '#fff',
  transition: { type: 'wipe', duration: 0.6, ease: CV.ease.swift, angle: 20, lineColor: '#f33' },
  draw(ctx, s) { … },
}
```

Timeline resolution: `scene.duration = duration ?? max(minDuration, voiceDelay + speech + tail)`. Consecutive scenes overlap by the transition's duration.

### The scene info object `s`

| Field | Meaning |
|---|---|
| `s.t` | local time in seconds (0 at scene start, including the incoming transition) |
| `s.dur`, `s.p` | scene duration, and `t/dur` clamped to 0..1 |
| `s.T`, `s.frame`, `s.fps` | global time, frame index, fps |
| `s.W`, `s.H`, `s.u` | design size. `u` = short side / 1080 (use it to scale for other aspect ratios) |
| `s.enter`, `s.exit` | 0→1 progress of the incoming and outgoing transitions |
| `s.at(start, dur, ease?)` | eased 0→1 progress of a local window. The workhorse. |
| `s.when('phrase', fallback)` | **local time at which the phrase is spoken** (from TTS word boundaries). Use it for sync. |
| `s.voiceStart`, `s.voiceEnd` | when the narration starts and ends (local) |
| `s.voice` | `{text, duration, words:[{text,start,end}]}` or null |
| `s.isRender` | true inside the renderer |

## Transitions

Built-in `type`s: `cut`, `fade`, `dip` (`color`), `push` / `slide` (`direction`: left, right, up, down), `wipe` (`angle`, `softness`, `lineColor`, `lineWidth`), `iris` (`x`, `y` as 0..1), `zoom`, `blur`, `glitch` (`tint`, `seed`).
Custom: `type: (ctx, A, B, p, opts) => {…}`, where A and B are canvases of the outgoing and incoming scenes and `p` is eased 0→1.

## Easing & motion

- `CV.ease.*` — `linear, inQuad, outQuad, inOutQuad, inCubic, outCubic, inOutCubic, outQuart, inOutQuart, outQuint, inOutQuint, inExpo, outExpo, inOutExpo, outCirc, inOutSine, outBack(p, s)`. Intent names: `standard, enter, exit, swift, gentle`. Custom curves: `bezier(x1,y1,x2,y2)` (same as CSS).
- `CV.spring({stiffness, damping, mass, velocity})` → `(t) => 0..1` (closed form). Presets: `CV.spring.presets.smooth | snappy | bouncy | heavy`.
- `CV.progress(t, start, dur, ease)` → eased 0..1 over a window.
- `CV.tween(t, [[t0, v0], [t1, v1, ease], …])` → keyframes (numbers or arrays).
- `CV.springTrack(t, [[t0, v0], [t1, v1], …], springOpts)` → a spring-animated value re-targeted over time.
- `CV.clamp, lerp, invLerp, remap(v, a, b, c, d, ease), stagger(i, each, start)`.
- `CV.rand(seed)` → a seeded PRNG function. `CV.noise(x, seed)` → smooth value noise in −1..1.

## Motion primitives — `CV.fx`

- `fx.lineReveal(ctx, lines, x, y, t, {lineHeight, stagger, dur, ease, align, rise, exit})` — lines rise out of masks.
- `fx.charReveal(ctx, str, x, y, t, {stagger, dur, rise, blur, align, maxWidth})` — per-glyph fade, rise and unblur. Returns the glyph layout.
- `fx.countUp(p, from, to, {decimals, sep, prefix, suffix})` → formatted string.
- `fx.typewriter(str, p, {caret, t})` → a substring (grapheme-safe).
- `fx.mask(ctx, x, y, w, h, fn)` — clip drawing to a rectangle.
- `fx.onTwos(t, fps, n)` — quantised time for hand-made, animate-on-twos motion.

## Text — `CV.text`

- `text.wrap(ctx, str, maxWidth)` → lines. CJK-aware with kinsoku (no `，。！？）` at line start, no `（《“` at line end). Latin words and numbers stay whole.
- `text.fitSize(ctx, str, '900 {size}px "Font"', maxWidth, max, min)` → the largest size that fits (and sets `ctx.font`).
- `text.glyphs(ctx, str, x, y, {maxWidth, lineHeight, align})` → `[{ch, x, y, w, i, line}]` for per-glyph animation.
- `text.words(…)` → word or CJK-character units with positions.

## Drawing — `CV.draw`, `CV.color`

- `draw.roundRect, drawOn(ctx, pts, p)` (progressive stroke), `sketchLine(x1,y1,x2,y2,{seed, roughness})`, `sketchCircle(cx,cy,r,{seed, roughness, steps})`, `grain(ctx, frame, amount, {blend})`, `vignette(ctx, W, H, amount, color)`, `camera(ctx, W, H, {zoom, x, y, rotate, focusX, focusY}, fn)`.
- `color.rgba(c, a)`, `color.mix(a, b, p)`, `color.parse(c)`.
- `CV.image(src)` preloads an image (the renderer waits for it). `CV.drawCover(ctx, img, x, y, w, h, fx, fy)` draws it cover-fit.
- WebGL: create your own `<canvas>` or `OffscreenCanvas` with a `webgl2` context, render your shader for `s.t`, then `ctx.drawImage(glCanvas, 0, 0)`. Call `gl.finish()` before drawing it. SwiftShader is available headless.

## Captions — `CV.subtitles`

- `subtitles.build(text, words, {maxChars, minChars, lang, punctuation, offset})` → cues `[{start, end, text, words}]`.
- `subtitles.draw(ctx, cues, t, style)`. Style keys: `font, color, highlight` (karaoke colour), `box` (background colour or null), `stroke, strokeWidth, y` (baseline as a fraction of H), `maxWidth, padX, padY, radius, lineHeight, fadeIn`.
- `subtitles.estimate(text, lang)` → an estimated `{duration, words}` before TTS exists.

The renderer burns captions with `--subs burn` (the same cues become `.srt` and `.vtt`).

## Renderer hooks (for tools)

`window.__CV` exposes `drawFrame(frame, subframe)`, `drawAt(t)`, `ready()`, `info()` (the resolved timeline, voice clips, cues, missing fonts) and `capture(type, quality)`.
